## Core paper claim window

This paper is intended to establish, conservatively, that:
- the particle-level effective description in TCV-phi is mesoscopic and patch-based rather than mono-cluster,
- `Q_SP` is the best current transport-level quasiparticle identity observable,
- collective collisions and recombinations generate reduced attractor classes,
- these classes support a robust charge-like ladder, a stabilized spectrum bridge, and a neutral observable mapping,
- and the resulting structure supports a controlled family-level rapprochement without claiming an exact Standard Model derivation.
