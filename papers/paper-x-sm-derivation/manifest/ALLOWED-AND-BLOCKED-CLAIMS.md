# Allowed And Blocked Claims

## Allowed
- The framework supports an exact gauge-product derivation and exact representation-side capstone.
- The framework supports a guarded theorem-style anomaly-dynamics package.
- The framework supports explicit hard-prediction candidates for `Lambda_TCV` and `m_Phi2`.
- `sin^2(theta_W)(Lambda_TCV)=0.375 +/- 0.050` is currently an external matching anchor, not a derived theorem output.
- The framework supports candidate routes for generation structure, CKM-like mixing, neutrino-spectrum transport splitting, and high-scale coupling unification.

## Blocked
- Any unconditional theorem-level anomaly-cancellation claim.
- Any statement that `sin^2(theta_W)=3/8` is already internally derived.
- Any licensed gauge-coupling unification claim.
- Any theorem-level derivation of exactly three generations.
- Any precision CKM or neutrino-spectrum fit.
